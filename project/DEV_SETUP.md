# Разовая настройка проекта

Пройди по порядку. После этого проект живёт сам — трогать больше не придётся.

## 1. Google Таблица

1. Создай новую Google Таблицу
2. Импортируй в неё `products-template.csv` из этого проекта: **Файл → Импорт → Загрузка → выбрать файл → Заменить текущий лист**
3. Проверь, что первая строка — заголовки столбцов (`id, category, name, ...`), а не заголовок листа
4. **Файл → Поделиться → Опубликовать в интернете (Publish to web)**
5. В первом выпадающем списке выбери нужный лист, во втором — **Значения, разделённые запятыми (.csv)**
6. Нажми **Опубликовать**, скопируй появившуюся ссылку — она понадобится в шаге 4

Проверь ссылку прямо в браузере — она должна сразу скачивать/показывать `.csv` файл, а не открывать саму таблицу.

## 2. GitHub-организация и репозиторий

Делаем через организацию, а не личный аккаунт — чтобы проект не отображался у тебя в профиле (обсуждали отдельно).

1. github.com → **+** (в правом верхнем углу) → **New organization** → бесплатный план
2. Назови организацию (например, по имени бизнеса)
3. Внутри организации: **New repository**, название любое, **Public** (обязательно — GitHub Pages бесплатно работает только с публичными репозиториями)
4. Загрузи туда содержимое папки проекта (через VS Code + git, либо перетаскиванием файлов в вебе — на старте можно и так)

## 3. Настройка синхронизации

1. В репозитории: **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**
2. Имя: `SHEET_CSV_URL`
3. Значение: ссылка из шага 1.6
4. Save

## 4. Права для автокоммита

1. **Settings → Actions → General → прокрутить до Workflow permissions**
2. Выбрать **Read and write permissions**
3. Save

(Обычно наш workflow сам запрашивает нужные права, но если синхронизация начнёт падать с ошибкой доступа — первым делом проверь этот пункт.)

## 5. Включить GitHub Pages

1. **Settings → Pages**
2. Source: **GitHub Actions**

## 6. Первый запуск

1. Вкладка **Actions** в репозитории
2. Слева выбрать workflow **Sync catalog and deploy**
3. Кнопка **Run workflow** → **Run workflow**
4. Подождать, пока оба шага (sync, deploy) позеленеют
5. Ссылка на сайт появится в **Settings → Pages** сверху страницы

## 7. Реальные контакты

Замени плейсхолдеры перед тем, как показывать сайт клиентам:

- `js/common.js` — объект `CONTACT` в начале файла (телефон, WhatsApp, Telegram)
- `index.html` и `product.html` — номер телефона в шапке (3 места) и в разделе «Контакты» на главной
- Название бренда «Мототовары» — уже вписано в шапку и футер обеих страниц
- Адрес и часы работы — раздел «Контакты» на `index.html`
- Карта — сейчас плейсхолдер-блок `.contacts__map`, вставь iframe с Яндекс/Google Картами

После любых правок этих файлов — просто запушь в `main`, сайт передеплоится сам (это тоже часть того же workflow).
