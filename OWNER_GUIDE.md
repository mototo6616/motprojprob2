# Как управлять каталогом сайта

Всё управление — через одну Google Таблицу. Ничего программировать не нужно.
Изменения на сайте появляются автоматически в течение примерно 15 минут после правки таблицы.

## Таблица с товарами

Ссылка на таблицу: _(разработчик вставит сюда ссылку)_

Каждая строка — один товар. Столбцы:

| Столбец | Что писать | Пример |
|---|---|---|
| `id` | Короткий код товара латиницей, без пробелов. Придумывается один раз при создании и потом не меняется | `electro-city-60` |
| `category` | Одно из трёх: `electro`, `pitbike`, `quad` | `pitbike` |
| `name` | Название товара | `Питбайк 125cc Cross` |
| `price` | Цена без знака ₽ | `79 900` |
| `characteristics` | Характеристики в формате `Название: значение`, через точку с запятой | `Объём: 125 см³; Скорость: 70 км/ч` |
| `description` | Полное описание для страницы товара | Обычный текст, любой длины |
| `photos` | Названия файлов фото через запятую, в том порядке, в котором они должны листаться на сайте (см. ниже, как их загрузить) | `city-60-1.jpg, city-60-2.jpg` |
| `in_stock` | `TRUE`, если в наличии, `FALSE`, если нет | `TRUE` |

### Добавить товар
Просто добавь новую строку снизу и заполни все столбцы. Придумай `id`, которого ещё нет в таблице.

### Убрать товар из продажи
Не обязательно удалять строку — если товара временно нет, просто поставь `FALSE` в столбец `in_stock`. Товар останется в таблице, но на сайте будет показан как "нет в наличии" (или можно вообще скрыть — скажи разработчику один раз, как вам удобнее).

Если товара не будет никогда — удали строку целиком.

### Изменить цену / описание / характеристики
Просто отредактируй нужную ячейку. Всё остальное менять не нужно.

## Как добавить фото товара

Фото хранятся не в самой таблице, а в отдельной папке проекта на GitHub. Это разовая привычка, но она простая:

1. Перейди в репозиторий проекта на GitHub → папка `img/products`
2. Нажми **Add file → Upload files**
3. Перетащи фото товара (можно сразу несколько)
4. Внизу страницы нажми **Commit changes**
5. Вернись в таблицу и в столбце `photos` впиши имя файла (или несколько через запятую), как ты назвал(а) их при загрузке

Через 10–15 минут фото появятся на сайте. Если указано больше одного фото — на сайте они автоматически превращаются в листалку (стрелки и свайп пальцем), ничего дополнительно настраивать не нужно.

## Как быстро обновляется сайт

Примерно каждые 15 минут сайт сам проверяет таблицу и подтягивает изменения — ничего дополнительно нажимать не нужно. Если очень нужно обновить прямо сейчас — скажи разработчику, он покажет, где нажать кнопку ручного запуска (это буквально одна кнопка в GitHub, без всякого кода).
